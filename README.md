# Compasmania - Pramuka SMAN 1 Jalaksana

Welcome to the **Compasmania** website repository! This project serves as the official platform for the Pramuka extracurricular at **SMAN 1 Jalaksana**, providing updates, information, and showcasing achievements. The website is built using **Laravel** for the backend, **Bootstrap** for the frontend styling, and **MySQL** as the database.

## Features

- **Activity Updates**: Stay up to date with recent and upcoming Pramuka events, such as camps, trainings, and other activities.
- **Photo Gallery**: View photos from our Pramuka events and activities.
- **Achievements**: Showcase the awards and accomplishments of our Pramuka team.
- **Announcements**: Stay informed with important news and updates.
- **Leadership & Members**: Profiles of the Pramuka leadership and members.

## Tech Stack

- **Laravel**: Used for building the backend and handling server-side logic, routing, and controllers.
- **Bootstrap**: A responsive front-end framework for designing clean and modern UI elements.
- **MySQL**: A relational database used to store Pramuka activities, announcements, and member profiles.
